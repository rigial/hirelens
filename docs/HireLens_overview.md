## HireLens

**HireLens** is a privacy-first, AI-powered desktop application that helps HR teams automate and simplify the candidate screening process.

HR can create job openings, define required skills and qualifications, and upload multiple resumes in PDF or DOC/DOCX format. HireLens processes the resumes locally using an on-device LLM, extracts relevant candidate information, compares it against the job requirements, and ranks candidates based on their skills, experience, and overall relevance.

The application is designed to run entirely on the user's machine, keeping sensitive job and candidate data private without requiring resumes to be uploaded to external servers.

### Core Workflow

```text
Create Job
    ↓
Define Skills & Requirements
    ↓
Upload Multiple Resumes
    ↓
Local Resume Parsing
    ↓
AI Candidate Analysis
    ↓
Skill & Experience Matching
    ↓
Candidate Ranking
    ↓
HR Review
    ↓
Shortlist Candidates
```

### Key Features

* 🖥️ **Cross-platform desktop app** — macOS, Windows, and Linux
* 🔒 **Privacy-first** — candidate data stays on the local machine
* 🤖 **Local AI** — resume analysis powered by an on-device LLM
* 📄 **Resume parsing** — supports PDF and DOC/DOCX resumes
* 🎯 **Job matching** — compares candidates against job requirements
* 📊 **Candidate ranking** — ranks candidates based on configurable criteria
* 🔍 **AI insights** — highlights strengths, missing skills, and relevant experience
* 👥 **Candidate management** — organize and manage candidates for each job
* ⭐ **Shortlisting** — allow HR to manually review and shortlist candidates
* 💾 **Local database** — jobs, resumes, analysis, and candidate information stored locally
* ⚡ **Background processing** — process multiple resumes without blocking the HR workflow

### One-line description

> **HireLens is a privacy-first local AI hiring assistant that helps HR teams analyze, compare, rank, and shortlist candidates faster.**
